場合の数と確率1

\(1, 2, 3, \dots, n\) の数字が 1 つずつ書かれた \(n\) 枚のカードがある（ただし \(n \ge 2\) とする）。 この \(n\) 枚のカードを 1 枚ずつ元に戻さずにすべて取り出し、取り出した順に \(a_1, a_2, a_3, \dots, a_n\) とする。 各回、残っているどのカードも等しい確率で取り出されるものとする。

得点を次のように定める。

  • \(a_1 < a_2 < a_3 < \dots < a_n\) が成り立つとき、得点を \(n\) 点とする。
  • 上記以外の場合、\(a_m > a_{m+1}\) となる最小の自然数 \(m\) を得点とする。

このとき、以下の問いに答えよ。

(1) 得点が \(n\) 点となる確率を求めよ。
(2) 得点が \(k\) 点となる確率を求めよ。ただし、\(k\) は \(1 \le k \le n-1\) を満たす自然数とする。
(3) 得点の期待値を \(E(n)\) とするとき、極限値 \(\lim_{n \to \infty} E(n)\) を求めよ。
ただし、\(\lim_{n \to \infty} \sum_{j=0}^{n} \frac{1}{j!} = e\) を証明なしに用いてよい。
数列の極限1

\(\alpha\) を \(\alpha \ge -1\) を満たす実数とし、数列 \(\{a_n\}\) を以下の漸化式によって定める。

$$ \begin{cases} a_1 = \alpha \\[4pt] a_{n+1}^2 = \dfrac{1 + a_n}{2} \quad (a_{n+1} \ge 0, \quad n = 1, 2, 3, \dots) \end{cases} $$

このとき、極限値 \(\displaystyle \lim_{n \to \infty} a_n\) を求めよ。

\(n\) を自然数とする。
数列 \(\displaystyle a_n = \frac{n! \, e^n}{n^n \sqrt{n}}\) はある正の定数 \(C\) に収束することが知られている。
また、\(\displaystyle I_n = \int_0^{\frac{\pi}{2}} \sin^n x \, dx \quad (n = 0, 1, 2, \dots)\) とする。
以下の問に答えよ。

(1) \(n \ge 1\) で \(\displaystyle I_{2n+1} < I_{2n} < I_{2n-1}\) を示せ。
(2) \(\displaystyle I_{n+2} = \frac{n+1}{n+2} I_n\) を示せ。
(3) 極限 \(\displaystyle \lim_{n \to \infty} \frac{I_{2n}}{I_{2n+1}}\) の値を求めよ。
(4) 定数 \(C\) の値を求めよ。
空間図形1

1辺の長さが \(2\) の正四面体 \(OABC\) がある。面 \(ABC\) 上（辺および頂点を含む）に点 \(P\) をとる。

正四面体の表面に沿って頂点 \(O\) から点 \(P\) まで進むときの最短距離を \(l\) とする。

点 \(P\) が面 \(ABC\) 上を動くとき、\(l\) の最大値と、その最大値をとる点 \(P\) の位置を求めよ。

微分法の応用1

\(n\) 個の正の実数 \(x_1, x_2, x_3, \dots, x_n\) が \(\displaystyle \sum_{k=1}^{n} x_k = 1\) を満たしながら動くとき、 $$x_1^{x_1} \cdot x_2^{x_2} \cdot x_3^{x_3} \cdots x_n^{x_n}$$ の最小値を求めよ。

場合の数と確率1 - 解答・解説
(1) の解答

得点が \(n\) 点となるのは、取り出したカードが \(a_1 < a_2 < \dots < a_n\) と並ぶ場合に限られる。
\(n\) 枚のカードの並べ方の総数は \(n!\) 通りあり、そのうち完全な昇順になる並べ方は \((1, 2, \dots, n)\) の 1 通りである。
したがって、求める確率は \(\displaystyle \frac{1}{n!}\) である。

(2) の解答

得点が \(k\) 点（\(1 \le k \le n-1\)）となる条件は、\(a_1 < a_2 < \dots < a_k\) かつ \(a_k > a_{k+1}\) が成り立つことである。
条件を満たす並べ方の総数を以下のように決定する。

  1. 最初の \(k+1\) つの位置に配置する \(k+1\) 枚のカードの選び方は \({}_n\mathrm{C}_{k+1}\) 通り。
  2. 選ばれた \(k+1\) 枚の中で最大の値は \(a_k\) に確定する。残りの \(k\) 枚のうち \(a_{k+1}\) に入る数の選び方は \(k\) 通り。残った \(k-1\) 枚の数は \(a_1 < a_2 < \dots < a_{k-1}\) に自動的（1通り）に配置される。
  3. 残り \(n-(k+1)\) 枚のカードの並べ方は \((n-k-1)!\) 通り。

並べ方の総数は、 $${}_n\mathrm{C}_{k+1} \times k \times (n-k-1)! = \frac{n!}{(k+1)!(n-k-1)!} \times k \times (n-k-1)! = \frac{n! \cdot k}{(k+1)!}$$ 全事象 \(n!\) 通りで割ることにより、求める確率は、 $$\frac{\frac{n! \cdot k}{(k+1)!}}{n!} = \frac{k}{(k+1)!}$$

(3) の解答

得点を表す確率変数を \(X\) とすると、期待値 \(E(n)\) は、 $$E(n) = \sum_{k=1}^{n-1} k \cdot P(X=k) + n \cdot P(X=n) = \sum_{k=1}^{n-1} \frac{k^2}{(k+1)!} + \frac{n}{n!}$$ ここで、\(\frac{k^2}{(k+1)!}\) の分子を変形すると、 $$\frac{k^2}{(k+1)!} = \frac{k(k+1) - (k+1) + 1}{(k+1)!} = \left( \frac{1}{(k-1)!} - \frac{1}{k!} \right) + \frac{1}{(k+1)!}$$ これを \(k=1\) から \(n-1\) まで足し合わせると、第一項の和は相殺により、 $$\sum_{k=1}^{n-1} \frac{k^2}{(k+1)!} = \left( 1 - \frac{1}{(n-1)!} \right) + \sum_{j=2}^{n} \frac{1}{j!} = \sum_{j=1}^{n} \frac{1}{j!} - \frac{1}{(n-1)!}$$ ここに第二項 \(\frac{n}{n!} = \frac{1}{(n-1)!}\) を加えると、 $$E(n) = \sum_{j=1}^{n} \frac{1}{j!}$$ 与えられた条件 \(\lim_{n \to \infty} \sum_{j=0}^{n} \frac{1}{j!} = e\) を用いると、 $$\lim_{n \to \infty} E(n) = \lim_{n \to \infty} \left( \sum_{j=0}^{n} \frac{1}{j!} - \frac{1}{0!} \right) = e - 1$$

【答】
(1) \(\displaystyle \frac{1}{n!}\)          (2) \(\displaystyle \frac{k}{(k+1)!}\)          (3) \(\displaystyle e - 1\)
数列の極限1 - 解答・解説
【解答】

\(a_1 = \alpha \ge -1\) より、 $$a_2 = \sqrt{\frac{1+\alpha}{2}} \ge 0$$ となる。漸化式の条件 \(a_{n+1} \ge 0\) より、\(n \ge 2\) において各項は \(a_n \ge 0\) であり、 $$a_{n+1} = \sqrt{\frac{1+a_n}{2}} \ge \frac{1}{\sqrt{2}}$$ が成り立つ。

ここで、\(n \ge 2\) において $$|a_{n+1} - 1| = \left| \sqrt{\frac{1+a_n}{2}} - 1 \right| = \frac{\left| \frac{1+a_n}{2} - 1 \right|}{\sqrt{\frac{1+a_n}{2}} + 1} = \frac{|a_n - 1|}{2(a_{n+1} + 1)}$$ また、

\(a_{n+1} \ge \frac{1}{\sqrt{2}} > 0\) より \(2(a_{n+1} + 1) > 2\) であるから、 $$|a_{n+1} - 1| \le \frac{1}{2} |a_n - 1| \quad (n \ge 2)$$ が得られる。

これを繰り返し適用すると、 $$0 \le |a_n - 1| \le \left(\frac{1}{2}\right)^{n-2} |a_2 - 1| \quad (n \ge 2)$$ となる。

\(n \to \infty\) のとき \(\displaystyle \left(\frac{1}{2}\right)^{n-2} |a_2 - 1| \to 0\) であるから、はさみうちの原理より、 $$\lim_{n \to \infty} |a_n - 1| = 0$$ すなわち、 $$\lim_{n \to \infty} a_n = 1$$

【答】
$$\lim_{n \to \infty} a_n = 1$$
数列の極限2 - 解答・解説
(1) の解答

\(0 < x < \frac{\pi}{2}\) において \(0 < \sin x < 1\) より、各辺に \(\sin^{2n-1} x \) と \(\sin^{2n} x \) をそれぞれ掛けると、 $$0 < \sin^{2n+1} x < \sin^{2n} x < \sin^{2n-1} x$$ \(0\) から \(\frac{\pi}{2}\) まで定積分すると、 $$\int_0^{\frac{\pi}{2}} \sin^{2n+1} x \, dx < \int_0^{\frac{\pi}{2}} \sin^{2n} x \, dx < \int_0^{\frac{\pi}{2}} \sin^{2n-1} x \, dx$$ すなわち \(I_{2n+1} < I_{2n} < I_{2n-1}\) となる。

(2) の解答

部分積分より、 $$I_{n+2} = \int_0^{\frac{\pi}{2}} \sin^{n+1} x (-\cos x)' \, dx = \left[ -\sin^{n+1} x \cos x \right]_0^{\frac{\pi}{2}} + (n+1) \int_0^{\frac{\pi}{2}} \sin^n x \cos^2 x \, dx$$ 第一項は \(0\) であり、\(\cos^2 x = 1 - \sin^2 x\) を代入すると、 $$I_{n+2} = (n+1) \int_0^{\frac{\pi}{2}} \sin^n x (1 - \sin^2 x) \, dx = (n+1) I_n - (n+1) I_{n+2}$$ 整理すると \((n+2) I_{n+2} = (n+1) I_n\) となるため、両辺を \(n+2\) で割ることで次を得る。 $$I_{n+2} = \frac{n+1}{n+2} I_n$$

(3) の解答

(2) の結果より \(\displaystyle \frac{I_{2n-1}}{I_{2n+1}} = \frac{2n+1}{2n} = 1 + \frac{1}{2n}\) である。
また、(1)で示した不等式より\(\displaystyle 1 < \frac{I_{2n}}{I_{2n+1}} < \frac{I_{2n-1}}{I_{2n+1}}\)であるから、\(\displaystyle \lim_{n \to \infty} \left(1 + \frac{1}{2n}\right) = 1\) であることと、はさみうちの原理より、 $$\lim_{n \to \infty} \frac{I_{2n}}{I_{2n+1}} = 1$$

(4) の解答

(2) の漸化式を繰り返し用いると（\(I_0 = \frac{\pi}{2}, I_1 = 1\)）、 $$I_{2n} = \frac{(2n)!}{2^{2n} (n!)^2} \frac{\pi}{2}, \quad I_{2n+1} = \frac{2^{2n} (n!)^2}{(2n+1)!}$$ よって、 $$\frac{I_{2n}}{I_{2n+1}} = \frac{\{(2n)!\}^2 (2n+1) \pi}{2^{4n+1} (n!)^4}$$ ここで \(\displaystyle a_n = \frac{n! e^n}{n^n \sqrt{n}}\) より \(\displaystyle n! = \frac{a_n n^n \sqrt{n}}{e^n}\) および \(\displaystyle (2n)! = \frac{a_{2n} (2n)^{2n} \sqrt{2n}}{e^{2n}}\) を代入して整理すると、 $$\frac{I_{2n}}{I_{2n+1}} = \frac{a_{2n}^2}{a_n^4} \left(2 + \frac{1}{n}\right) \pi$$ 両辺の \(n \to \infty\) における極限をとると、(3) の結果および \(\displaystyle \lim_{n \to \infty} a_n = C\)（\(C > 0\)）より、 $$1 = \frac{C^2}{C^4} \cdot 2\pi = \frac{2\pi}{C^2}$$ \(C > 0\) より、\(C = \sqrt{2\pi}\) である。

【答】
(1) 証明略          (2) 証明略          (3) \(1\)          (4) \(\sqrt{2\pi}\)
空間図形1 - 解答・解説
最短経路を平面で考える

面 \(ABC\) 以外の3面は、いずれも \(O\) を含む。\(O\) から \(P\) への経路が初めて面 \(ABC\) に達する点を \(Q\) とする。

\(Q\) は面 \(ABC\) の辺上にあり、\(O,Q\) をともに含む側面がある。したがって、\(Q\) までの経路は、その側面内の線分 \(OQ\) で置き換えても長くならない。また、\(Q\) から先は面 \(ABC\) 内の線分 \(QP\) で置き換えてよい。

よって、側面を1つ通ってから面 \(ABC\) に入る3通りの経路だけを考えれば十分である。

面 \(ABC\) を平面上に置き、3つの側面をそれぞれ外側に開く。このときの \(O\) の移った点を、辺 \(BC,CA,AB\) に対応させて \(O_1,O_2,O_3\) とする。

各線分 \(O_iP\) は対応する辺を横切り、展開した2面の中を通るので、実際の経路になる。したがって、

\(\displaystyle l=\min\{O_1P,O_2P,O_3P\}\)…①
対称性を利用して範囲を絞る

この平面上に座標をとり、

$$A=(0,\sqrt3),\quad B=(-1,0),\quad C=(1,0)$$

とする。側面も1辺の長さが \(2\) の正三角形なので、

$$O_1=(0,-\sqrt3),\quad O_2=(2,\sqrt3),\quad O_3=(-2,\sqrt3)$$

である。\(P=(x,y)\) とおくと、\(y\ge0\) であり、

$$O_1P^2=x^2+(y+\sqrt3)^2$$ $$O_2P^2=(x-2)^2+(y-\sqrt3)^2$$ $$O_3P^2=(x+2)^2+(y-\sqrt3)^2$$

となる。図形の回転対称性より、3つの距離のうち \(O_1P\) が最小となる場合を考えれば十分である。同じ最小値をとる距離が複数ある場合も含める。

距離の2乗の差をとると、

$$O_1P^2-O_2P^2=4(x+\sqrt3y-1)$$ $$O_1P^2-O_3P^2=4(-x+\sqrt3y-1)$$

であるから、\(O_1P\le O_2P,\ O_1P\le O_3P\) より、

$$|x|+\sqrt3y\le1$$

を得る。\(y\ge0\) と合わせると、

\(\displaystyle 0\le y\le\frac1{\sqrt3},\qquad |x|\le1-\sqrt3y\)…②

となる。この範囲は、\(G=(0,1/\sqrt3)\) を頂点とする三角形 \(BCG\) である。なお、\(G\) は三角形 \(ABC\) の重心である。

最大値と等号成立条件

①、②より、

$$\begin{aligned} l^2&=O_1P^2\\ &=x^2+(y+\sqrt3)^2\\ &\le(1-\sqrt3y)^2+(y+\sqrt3)^2\\ &=4+4y^2\\ &\le4+4\left(\frac1{\sqrt3}\right)^2\\ &=\frac{16}{3} \end{aligned}$$

等号が成立するのは \(y=1/\sqrt3\) のときであり、②より、このとき \(x=0\) である。すなわち \(P=G\) のときに限る。

実際に \(P=G\) とすると、3つの距離はすべて \(4/\sqrt3\) となる。\(G\) は回転によって動かないので、残りの対称な範囲にも別の等号成立点はない。

【答】

最大値は \(\displaystyle \frac{4\sqrt3}{3}\)

その最大値をとるのは、\(P\) が面 \(ABC\) の重心にあるとき。

【解答へのアプローチ】

表面上の最短経路は、面を開いて平面上の線分として考える。ただし、どの面を通るかによって長さが異なるため、3つの距離のうち最も短いものを比較する必要がある。

対称性から重心が候補と予想できるが、それだけでは最大性の証明にはならない。「どの距離が最小か」によって三角形を3つの範囲に分け、そのうち1つで上限を示すのがポイントである。

頂点 \(A,B,C\) では最短距離は \(2\) であるのに対し、重心では \(4\sqrt3/3\) となる。表面に沿って進む場合には、面の内部の点が最も遠くなる。

微分法の応用1 - 解答・解説
【解答・解説】

\(f(x) = x \log x \ (x > 0)\) とおく。
\(f'(x) = \log x + 1\), \(f''(x) = \frac{1}{x} > 0\) より、\(y = f(x)\) は \(x > 0\) において下に凸な関数である。……①

\(x = \frac{1}{n}\) における \(y = f(x)\) の接線の方程式は、 $$y - f\left(\frac{1}{n}\right) = f'\left(\frac{1}{n}\right)\left(x - \frac{1}{n}\right)$$ $$y = (1 - \log n)x - \frac{1}{n}$$

①より、接線は常に曲線 \(y = f(x)\) の下側に位置するため、すべての \(x > 0\) に対して次の不等式が成り立つ。 $$x \log x \ge (1 - \log n)x - \frac{1}{n} \quad \dots\dots ②$$

不等式 ② の \(x\) に \(x_1, x_2, \dots, x_n\) をそれぞれ代入して足し合わせると、 $$\sum_{k=1}^{n} x_k \log x_k \ge \sum_{k=1}^{n} \left\{ (1 - \log n)x_k - \frac{1}{n} \right\}$$ $$= (1 - \log n)\sum_{k=1}^{n} x_k - \sum_{k=1}^{n} \frac{1}{n}$$ \(\sum_{k=1}^{n} x_k = 1\) より、 $$\sum_{k=1}^{n} x_k \log x_k \ge (1 - \log n) \cdot 1 - 1 = -\log n$$

等号成立条件は、すべての \(k \ (1 \le k \le n)\) について \(x = x_k\) が接点 \(x = \frac{1}{n}\) と一致するとき、すなわち $$x_1 = x_2 = \dots = x_n = \frac{1}{n}$$ のときである。
したがって、\(\displaystyle \sum_{k=1}^{n} x_k \log x_k\) の最小値は \(-\log n\) となる。

ここで、 $$\log \left( x_1^{x_1} \cdot x_2^{x_2} \cdots x_n^{x_n} \right) = \log x_1^{x_1} + \log x_2^{x_2} + \dots + \log x_n^{x_n} = \sum_{k=1}^{n} x_k \log x_k$$ であるから、\(\log \left( x_1^{x_1} \cdot x_2^{x_2} \cdots x_n^{x_n} \right)\) の最小値も \(-\log n = \log \frac{1}{n}\) である。

よって求める最小値は \(\displaystyle \frac{1}{n}\) となる。

【答】
$$\frac{1}{n}$$
【解答へのアプローチ】

まず、各変数の対等性（対称性）から、最小値をとるのは \(x_1 = x_2 = \dots = x_n = \frac{1}{n}\) のときだと予想できる。

しかし、与式は底にも指数にも変数を含み、それらが掛け合わされているため、そのままの形で処理することは困難である。そこで対数をとる発想が自然に浮かぶ。

対数をとることで \(\displaystyle \sum_{k=1}^n x_k \log x_k\) の形になるが、ここで \(f(x) = x \log x\) が「下に凸な関数」であることに着目して欲しい。
目指すのは \(x_1 = x_2 = \dots = x_n = \frac{1}{n}\) での最小性の証明だから、\(x = \frac{1}{n}\) における接線を考えることで凸不等式を作り出し、等号成立条件の議論へ持ち込むことができる。

積分法1

\(a\) を正の実数とし、

$$f(a)=\int_0^1\frac{4ax^2(1-x^2)^2}{(1+x^2)^3\bigl\{(1-x^2)^2+4a^2x^2\bigr\}}\,dx$$

とおく。以下の問いに答えよ。

(1) $$g(a)=\int_0^{\pi/2}\frac{1}{\cos^2x+a^2\sin^2x}\,dx$$ を \(a\) を用いて表せ。
(2) $$A=\int_0^{\pi/2}\frac{\cos^2x}{\cos^2x+a^2\sin^2x}\,dx,$$ $$B=\int_0^{\pi/2}\frac{\sin^2x}{\cos^2x+a^2\sin^2x}\,dx$$ をそれぞれ \(a\) を用いて表せ。
(3) \(f(a)\) を \(a\) を用いて表せ。また、\(a\) が正の実数全体を動くときの \(f(a)\) の最大値を求めよ。
積分法1 - 解答・解説
(1) の解答

積分区間を \(x=\dfrac{\pi}{4}\) で分け、後半で \(x=\dfrac{\pi}{2}-\theta\) と置換する。前半の積分変数も \(\theta\) と書けば、

\(\displaystyle g(a)=\int_0^{\pi/4}\frac{d\theta}{\cos^2\theta+a^2\sin^2\theta} +\int_0^{\pi/4}\frac{d\theta}{\sin^2\theta+a^2\cos^2\theta}\)…①

ここで、\(\tan\alpha=a,\ 0<\alpha<\dfrac{\pi}{2}\) となる角 \(\alpha\) をとる。

①の第1項で \(a\tan\theta=\tan u\) と置換すると、

$$\frac{a}{\cos^2\theta}\,d\theta=\frac{1}{\cos^2u}\,du$$

よって、

$$\begin{aligned} \int_0^{\pi/4}\frac{d\theta}{\cos^2\theta+a^2\sin^2\theta} &=\int_0^{\pi/4}\frac{d\theta}{\cos^2\theta(1+a^2\tan^2\theta)}\\ &=\frac1a\int_0^\alpha du=\frac{\alpha}{a} \end{aligned}$$

①の第2項では、\(\tan\theta=a\tan u\) と置換する。このとき、

$$\frac{1}{\cos^2\theta}\,d\theta=\frac{a}{\cos^2u}\,du$$

また、\(\tan\left(\dfrac{\pi}{2}-\alpha\right)=\dfrac1a\) より、

$$\begin{aligned} \int_0^{\pi/4}\frac{d\theta}{\sin^2\theta+a^2\cos^2\theta} &=\int_0^{\pi/4}\frac{d\theta}{\cos^2\theta(\tan^2\theta+a^2)}\\ &=\frac1a\int_0^{\pi/2-\alpha}du =\frac{\pi/2-\alpha}{a} \end{aligned}$$

以上から、

$$g(a)=\frac{\pi}{2a}$$

\(\displaystyle A+B=g(a)=\frac{\pi}{2a}\)…②

(3) の解答

\(x=\tan\dfrac{\theta}{2}\) と置換すると、

$$0\leq\theta\leq\frac{\pi}{2},\qquad \frac{dx}{1+x^2}=\frac12\,d\theta$$

さらに、倍角公式から、

$$\frac{2x}{1+x^2}=\sin\theta,\qquad \frac{1-x^2}{1+x^2}=\cos\theta$$

であるから、

$$f(a)=\frac a2\int_0^{\pi/2}\frac{\sin^2\theta\cos^2\theta}{\cos^2\theta+a^2\sin^2\theta}\,d\theta$$

積分変数を \(x\) と書き直し、

$$J=\int_0^{\pi/2}\frac{\sin^2x\cos^2x}{\cos^2x+a^2\sin^2x}\,dx$$

とおけば、

\(\displaystyle f(a)=\frac a2J\)…④

ここで、

$$\cos^2x-\frac{\cos^2x}{\cos^2x+a^2\sin^2x} =\frac{(a^2-1)\sin^2x\cos^2x}{\cos^2x+a^2\sin^2x}$$

が成り立つ。両辺を積分し、(2) の結果を用いると、

$$\begin{aligned} (a^2-1)J&=\int_0^{\pi/2}\cos^2x\,dx-A\\ &=\frac{\pi}{4}-\frac{\pi}{2(a+1)} =\frac{\pi(a-1)}{4(a+1)} \end{aligned}$$

したがって、\(a\ne1\) のとき、

$$J=\frac{\pi}{4(a+1)^2}$$

④より、

$$f(a)=\frac{\pi a}{8(a+1)^2}$$

また、\(a=1\) のとき、

$$\begin{aligned} f(1)&=\frac12\int_0^{\pi/2}\sin^2x\cos^2x\,dx\\ &=\frac1{16}\int_0^{\pi/2}(1-\cos4x)\,dx =\frac{\pi}{32} \end{aligned}$$

これは上の式に \(a=1\) を代入した値と一致する。よって、

$$f(a)=\frac{\pi a}{8(a+1)^2}$$

最後に、

$$f(a)=\frac{\pi}{8\left(a+2+\frac1a\right)}$$

と変形する。\(a>0\) なので、相加相乗平均の関係より、

$$a+\frac1a\geq2\sqrt{a\cdot\frac1a}=2$$

したがって、

$$f(a)\leq\frac{\pi}{8(2+2)}=\frac{\pi}{32}$$

\(a=1\) のとき等号が成立するため、求める最大値は \(\dfrac{\pi}{32}\) である。

整数1

\(a,b\) を、\(a<b\) を満たす互いに素な正の整数とする。

(1) $$\frac{a^2+b^2}{(b-a)^2}$$ が整数ならば、\(b=a+1\) であることを示せ。
(2) \(s,m\) を \(s\geq3\) および \(s^2-2m^2=-1\) を満たす正の整数とし、 $$S=3s-4m,\qquad M=3m-2s$$ とおく。\(S,M\) は正の整数であり、\(S^2-2M^2=-1\) および \(S<s\) を満たすことを示せ。
(3) $$\frac{a^2+b^2}{(b-a)^2}$$ が平方数となり、かつ \(a+b<2027\) を満たす組 \((a,b)\) をすべて求めよ。
整数1 - 解答・解説
(1) の解答

\(d=b-a\) とおく。\(a,b\) は互いに素なので、\(d\) は \(a,b\) のいずれとも互いに素である。したがって、\(d^2\) と \(ab\) も互いに素である。

仮定より \(d^2\) は \(a^2+b^2\) を割り切り、

$$a^2+b^2=(b-a)^2+2ab=d^2+2ab$$

だから、\(d^2\) は \(2ab\) を割り切る。\(d^2\) と \(ab\) は互いに素なので、\(d^2\) は \(2\) の約数である。

\(d\) は正の整数であるから \(d=1\)。よって \(b=a+1\) である。

(2) の解答

条件を満たす \(s\geq3\) に対して、

$$S=3s-4m,\qquad M=3m-2s$$

とおくと、\(S,M\) は整数である。計算すると、

$$\begin{aligned} S^2-2M^2&=(3s-4m)^2-2(3m-2s)^2\\ &=s^2-2m^2\\ &=-1 \end{aligned}$$

である。また、仮定より、

$$m^2=\frac{s^2+1}{2}$$

したがって、

$$9s^2-16m^2=s^2-8>0$$

だから \(3s>4m\)、すなわち \(S>0\) である。同様に、

$$9m^2-4s^2=\frac{s^2+9}{2}>0$$

より \(M>0\) である。さらに、

$$4m^2-s^2=s^2+2>0$$

より \(2m>s\) なので、

$$S=3s-4m<s$$

よって、条件を満たす \(s\geq3\) の解から、同じ式を満たす、より小さい正の整数の解が得られる。

(3) の解答

(1) より \(b=a+1\) だから、ある正の整数 \(m\) を用いて、

$$a^2+(a+1)^2=m^2$$

と表せる。ここで、

$$s=2a+1=a+b$$

とおくと、

\(\displaystyle s^2-2m^2=-1\)…①

となる。求める範囲は \(3\leq s<2027\) である。

①を満たす正の整数の組を、大きな解から小さな解へ移す方法で調べる。

(2) より、①を満たす \(s\geq3\) の解から、同じ式を満たす、より小さい正の整数の解が得られる。

①から \(s\) は奇数である。上の操作を繰り返すと、\(s\) は正の整数の範囲で減少するため、最後には \(s=1\) となる。①より、このとき \(m=1\) である。

逆に、\(S=3s-4m,\ M=3m-2s\) を \(s,m\) について解くと、

$$s=3S+4M,\qquad m=2S+3M$$

したがって、すべての正の整数解は、\((1,1)\) から

$$(s,m)\longmapsto(3s+4m,\ 2s+3m)$$

を繰り返して得られる。この操作で得られる組も正の整数であり、

$$(3s+4m)^2-2(2s+3m)^2=s^2-2m^2=-1$$

なので、確かに①の解になる。

順に計算すると、

$$\begin{array}{c|r|c} s&m&(a,b)\\ \hline 1&1&(0,1)\\ 7&5&(3,4)\\ 41&29&(20,21)\\ 239&169&(119,120)\\ 1393&985&(696,697)\\ 8119&5741&(4059,4060) \end{array}$$

\(s=1\) のときは \(a=0\) となるので条件に合わない。また、\(s=8119\) は \(s<2027\) を満たさない。この生成操作では \(s\) は増加するため、これ以降の解も条件を満たさない。

残る4組は、いずれも連続する正の整数なので互いに素であり、すべての条件を満たす。
